Administrar la verificación en dos pasos

Esta página es solo para administradores.

Un usuario sin autenticador necesita un código de invitación para darlo de alta: genéralo aquí y entrégaselo por un canal seguro. Se muestra una sola vez, sirve una sola vez y caduca. «Reiniciar autenticador» borra el del usuario (cierra sus sesiones y no cambia su contraseña).
